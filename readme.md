# Personal website

Live: https://shuyangzhang-sde.github.io/

Source: https://github.com/shuyangzhang-sde/emmazhang-dev-personal-website

This repository publishes the Vite production build from the source repository.
To update it, run `npm ci` and `npm run build` in the source repository, then copy
the contents of `dist/` to this repository root, retaining `.nojekyll`, and push to `main`.
GitHub Pages publishes from `main` at `/`.
